# Placeholder Assets

Drop your hand-drawn art files here. The app references these by filename.

**GIFs work!** For animated stickmen/buttons, just use `.gif` files with the same basename
and update the path in the corresponding component file (e.g. `stickman-left-idle.gif`).

| Filename | Purpose | Suggested Size |
|---|---|---|
| `title.png` | Main menu title graphic | 600×200 |
| `btn-start.png` | Start button on menu | 200×80 |
| `btn-exit.png` | Exit button on menu | 200×80 |
| `btn-start-game.png` | "Start" on last tutorial slide | 200×80 |
| `background.png` | Full-screen background | 1920×1080 |
| `arrow-left.png` | Tutorial left arrow | 64×64 |
| `arrow-right.png` | Tutorial right arrow | 64×64 |
| `stickman-<colour>-idle.png` | Player idle skin (red, blue, green, or yellow) (or `.gif`) | 200×400 |
| `stickman-<colour>-holding.png` | Player holding remote skin (or `.gif`) | 200×400 |
| `stickman-<colour>-flying.png` | Player teleporting/grabbing mid-air (or `.gif`) | 200×400 |
| `desk-empty.png` | Just the desk with no player | 200×400 |
| `table.png` | Table in centre of game stage | 400×200 |
| `remote.png` | Remote on table | 80×80 |
